## Installation 

## 1

`git clone https://github.com/GFX-69/GFX-PANEL`

## 2

`cd GFX-PANEL`

## 3

`curl -sL https://deb.nodesource.com/setup_23.x | sudo bash - `

## 4

`apt-get install nodejs git`

## 5

`apt install zip -y && unzip panel1.zip && cd panel1`

## 6

`cd panel1 && cd panel`

## 7

`npm install && npm run seed`

## 8

`node .`
